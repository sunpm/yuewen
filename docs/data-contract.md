# 阅读报告数据契约

更新日期：2026-11-21。当前为无应用账号的单实例 Workers/D1 契约。旧用户、游客、后台及恢复接口已移除；历史上游观察和旧设计见 [归档契约](data-contract.legacy.md)，不是新实例的接口清单。

## 口径

| 数据       | 使用规则                                                                                                                                  |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 总时长     | 秒；使用不重叠自然周期的 `totalReadTime`，不用日明细之和替代官方总量                                                                      |
| 最近 24 月 | 从最早月份 1 日到上海时区当天；本月是不完整月                                                                                             |
| 采集策略   | 周、月、全部历史复用对应 `period` 回包的偏好，不额外请求年报；自然年与最近 24 月仍按月取得日明细，另请求一次所选年或结束年份的年度偏好    |
| 阅读日     | 官方 `readDays`，每日满 60 秒；自然日均和阅读日均分母分别展示                                                                             |
| 书架       | 电子书数组 + 有声数组 + 非空文章收藏入口；未知私密状态单列                                                                                |
| 进度       | 0–100，1 就是 1%；不将专辑完结标记作为用户读完                                                                                            |
| 累计笔记   | 划线 + 想法/点评 + 书签；不重复增加点评                                                                                                   |
| 正文       | 只含个人划线及个人想法；书签无正文；不采集书籍全文                                                                                        |
| 偏好       | 周、月、自然年与全部历史使用各自周期；仅最近 24 月用结束年份的年度补充并直接标明截至日，不参与 24 月总量；不合并 Top 榜，分类权重不是占比 |
| 热力图     | 按自然年分行、按周排列的逐日日历；保留日记录原始分钟数，不推造缺失日                                                                      |
| 词频       | 中文分词，去除单字及常见停用词，展示前 40 词；用于回顾，不代表心理或人格结论                                                              |
| 未知/零    | 上游缺失字段为不可用，实际零保留为零；尚在采集与失败另行标注                                                                              |

本周/本月报告的“月度”模块展示当前请求的周期片段，并保留准确起止日。全部历史使用官方汇总与年桶，月度和日历模块显示未逐月采集的原因。

全年阅读日历按自然年分行、按周排列，每格对应一天，包含闰年的 2 月 29 日。仅按当前报告已取得的逐日阅读分钟数高亮；未阅读、范围外、未来及未取得日明细的日期保留浅色底格。补齐底格只用于展示，不补造数据表与导出 JSON 中的阅读记录。

## 前端契约

`shared/report.ts` 定义 `ReadingReport` 与 27 个模块目录。每个模块都有 `id`、`title`、`section`、`scope`、`unit`、`status`、`description`、`coverage` 和 `data`。状态为 `ready / empty / unavailable / partial`。

`summary` 区分未知值与零；`books` 仅保留显示所需字段；`notes` 保留稳定 ID、书名、作者、日期、章节、正文、类型和可选对应原文。画像包含有指标依据的文字、来自真实划线的顶部选句、最多 20 条精选。模拟示例始终标记 `sampleReport: true`。

电子书的 `Book.category` 是一级分类，`rawCategory` 保留已返回的原始分类；空白、缺失或“未分类”按已确认业务规则统一为“导入书籍”，并设 `imported: true`。有声内容、文章收藏保留独立类别。缺作者、出版社或简介不会额外触发导入分类。书架筛选、模块 17 和 JSON 复用同一归一结果；HTML 的书架分类统计同口径。详情接口使用报告内已采集字段；两端合并详情时忽略空字符串及缺失值，并保持书架的分类、原始分类和导入标识。

报告响应先返回最多 200 条正文，前端在采集结束后通过 `/notes?cursor=` 补齐余下分页。分页未齐时不允许导出，避免误称完整。浏览器只使用内存保存阅读正文；localStorage 仅保存主题。旧 Vue 入口的浏览器历史条目保留页面筛选、章节与笔记展开数量，不存入报告内容或凭证。React PC 的搜索、分类、章节、展开数量与滚动位置仅保存在内存中，按来源和任务隔离，最多保留 24 个访问条目；前进/后退可恢复，刷新不恢复私有筛选。

页面 URL 的 `range=recent/weekly/monthly/overall/年份` 是显式来源；年份为 `2015` 至上海时区当年。缺失、重复或非法页面参数以 `replace` 归一为 `recent`；API 非法值仍返回 `INVALID_INPUT`。用户切换范围形成历史记录并清除月份筛选。有效的较早年份补入选择器，导航、单书笔记及返回导航保留范围；只恢复匹配范围的报告。前端串行提交创建请求，并检查创建、批次与笔记分页的调用代次；离开旧页面在新页面初始化前停止推进。

模块 9–14 的 `scope` 表达实际周期，最近 24 月明确标记「年度偏好，非最近 24 月汇总」。旧周/月/全历史采集状态重新聚合对应 `period`，忽略旧 `preference` 年度数据；没有对应来源则提示重读。缺失字段为不可用、空数组为空、数值零保留；正在读取和失败使用相应原因说明。

模块 13 使用 `kind: authors`；`Datum.label` 仅为作者名称，`value` 为数值本数，`readTime?: string` 保留上游格式化时长，缺失不补零也不解析为数值。数据按本数稳定降序，真实零保留；卡片只显示前 5 位，弹窗、HTML 明细和 JSON 保留全部已返回记录。实例接口从保存的原始采集状态重聚合报告，时长缺失显示“—”，不从旧标签猜测。示例时长仅汇总其自身模拟记录。

模块 25 的分词、停用词与前 40 词口径保持不变；SVG 云图的布局位置与字号不进入 JSON。云图长词省略不改变 `label`，完整词语和频次仍在提示、明细及 JSON 中保留；HTML 同时嵌入静态词云和完整词频表。

## 服务端接口

只有 `/api/health`、`/api/demo?range=...` 公开。其他 API 必须通过部署 Access 保护或本地独立开发入口；写入要求同源 Origin。应用不保存用户资料或身份会话。详见[安全边界](self-host-cloudflare.md#安全与数据边界)。

| 接口                                      | 行为                                                                                                                 |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `GET /api/connections`                    | 返回 `instance.status/context/expiresAt` 与 `serverTime`；状态只说明上游 Secret 是否配置，不回显 Key、不验证有效性。 |
| `GET /api/session/reports`                | 恢复当前实例未到期报告。路径中的 session 仅为前端兼容命名，没有用户会话。                                            |
| `DELETE /api/session/reports`             | 清除当前报告，保留历史存档。                                                                                         |
| `GET /api/reports/target`                 | 返回当前目标 `id/keyVersion`，供替换确认。                                                                           |
| `POST /api/reports`                       | `{range,requestId,expected:{id},replace}`；幂等创建。已有报告必须明确确认替换，目标变化返回 409。                    |
| `GET /api/reports/:id`                    | 返回有期限的任务与前 200 条笔记。                                                                                    |
| `GET /api/reports/:id/notes?cursor=0`     | 正文分页与版本；游标必须非负整数。                                                                                   |
| `POST /api/reports/:id/advance`           | `{version}`，有界推进一次上游操作，D1 租约防止同时读取；保存游标、预算和错误退避。                                   |
| `POST /api/reports/:id/cancel`            | 停止采集，保留已有结果。                                                                                             |
| `POST /api/reports/:id/retry`、`continue` | 重试或在预算允许时开启下一段；不延长原期限。PC 提供续段入口。                                                        |
| `POST /api/reports/:id/touch`             | 核验仍有效，不延长期限。                                                                                             |
| `GET /api/books/:id`                      | 只返回当前报告中的书籍字段，不额外请求上游。                                                                         |
| `POST /api/archives`                      | `{reportId,version,includeNotes}`；停止/完成后保存快照，重复同版本同正文选择返回同一 ID。                            |
| `GET /api/archives`                       | `{items,limit,maxBytes}`；列表不带报告正文。                                                                         |
| `GET /api/archives/:id`                   | 快照和摘要，复用报告渲染与下载。                                                                                     |
| `DELETE /api/archives/:id`                | 删除指定快照，级联清除 JSON 分块。                                                                                   |

## 存储与采集期限

D1 `entity` 保存版本、内部并发 token、摘要，`chunk` 保存 Unicode 安全分块 JSON；`collection_lease` 为短期读取租约。没有 user/account/guest/session/credential 表。Key 只在 Worker Secret；当前报告内部只存授权哈希，变更 Secret 后拒绝旧任务继续采集，以免混合不同来源数据。API 不返回哈希。

当前报告最长两小时；到期立即拒读，小时 Cron 清理。当前报告替换或清除不影响已保存快照。D1 batch 原子写入且比较版本与内部 token；晚到采集不能复活已删除/替换报告。

<a id="segmented-collection"></a>

### 超预算分段续采

沿用采集器每段最多 600 请求、10000 条笔记、约 1.5 MB 状态预算，最多 4 段。正文合并去重；未知上游字段不补造。错误发生前消耗的请求数、分页位置和退避也持久化。总序列化状态额外限制 10 MiB。实际容量、耗时与免费/付费 Workers CPU 配额需要部署者结合自身数据验证。

### 长期报告存档

每实例最多 20 份，快照最多 2 MiB。默认不存正文，并去除画像选句和精选正文；选择包含正文时保存完整已采集正文。保存不额外请求上游。历史数据保留至主动删除，HTML/JSON 下载由浏览器完成；不会自动导入旧库。

## 保护与下载

模拟数据标记 `sampleReport: true`；真实实例来源为 `instance`。公共构建无开发数据入口。API 私有响应不缓存，客户端在访问拒绝/报告失效时清除内存报告。下载内容不含 Worker Key、Access JWT、内部 token 或用户身份字段。HTML 转义正文并内嵌 SVG，无远端脚本；实际格式与例子见 `client/export.ts`、`shared/report.ts`。

验证证据：[本次质量记录](quality-log.md#self-host-2026-11-21)。真实上游、真实 Access 域名与远端迁移未在本轮执行。
