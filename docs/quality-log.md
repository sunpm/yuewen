### 失败与修复

最终路由复核发现无显式连接时，范围参数自动归一会改变完整 URL，使连接状态响应被误判为过期，页面停留在恢复状态。现改为检查页面路径与是否已有明确选择，允许同页面范围归一后继续恢复连接；没有放宽已显式选择时的来源隔离。

迁移最初受 `tsx` 管道权限阻止；提权又因数据库目标不明被自动审批拒绝。核对文档和脱敏配置，确认开发是回环应用地址且与生产为不同 Neon endpoint 后，审批允许开发迁移并执行成功，没有修改生产配置。

游客实调发现共享限流 SQL 直接插值 `Date` 导致服务错误，改为明确时间戳字符串及 PostgreSQL 类型后接入成功。一次 API 请求因独立监听进程随代码修改重启而收到空响应，服务稳定后重新执行通过。普通构建曾因宿主 `EMFILE` 文件监听限制失败，使用本次命令的 polling 选项后成功；首次格式检查指出契约文档格式，修正后全仓通过。

#### Firefox 环境失败

本机 Playwright Firefox 1543 启动输出 `Could not find profile folder.`，进程立即退出。改用临时目录后结果相同。现象与 [Playwright 的 macOS 27 跟踪问题](https://github.com/microsoft/playwright/issues/42768)一致，但尚未独立证明根因。保留 Firefox 项目及全部断言，没有通过跳过用例将整套测试标成成功。
