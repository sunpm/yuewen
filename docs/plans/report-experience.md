### 时间范围、数据来源与路由

1. **URL 为显式范围来源。** 在共享 `client/useReadingReport.ts` 中统一读取、校验和同步范围，复用现有 `RangeKey`；本周、本月、最近 24 月、全部历史及 `2015` 至上海时区当年的四位年份为有效值，和服务端 `parseRange` 保持一致。当前选择器仅列最近三个年份，直接访问其他有效年份时须补入当前所选年份，不能出现 URL 有效而控件为空。缺失、重复数组或非法页面参数归一为默认最近 24 月；直接向 API 提交非法值仍按现有契约返回 `INVALID_INPUT`。用户主动切换范围可形成历史记录，初始化归一化使用 `replace`，避免双向监听循环、重复采集及旧响应覆盖。恢复缓存时只使用与目标范围匹配的报告；不新增 localStorage 阅读数据缓存。
2. **导航保留必要参数。** 主 tab、数据来源切换和单书笔记跳转继续携带 `range`，分别保留适用的 `view`、`source`、`book`、`month`，不以重建 query 的方式丢失范围。切换范围时清除不再适用的月份筛选，不能让遗留月份把新范围筛成空结果。登录返回保留完整目标地址及范围；游客实现后还须按[连接选择与恢复](guest-access.md#connection-selection)携带 `connection`，保存转换不改变当前范围。滚动行为与 [计划复核补充：五处关联细节](#notes-details) 一致：主动导航回顶，前进后退恢复位置，初始化归一化不额外回顶。
3. **优先使用匹配周期的官方数据。** 本周、本月、自然年与全部历史分别使用对应周期的排行和偏好；全历史直接复用 `period:overall` 中实际返回的 `readLongest`、`preferCategory`、`preferAuthor`、`preferPublisher` 等字段，不为同一目的重复请求当年年报。字段缺失、空数组、失败和实际零按既有状态规则区分，不静默回退到当前年，不从书架最近活动时间推算单书历史时长。
4. **跨年偏好单独明确年度口径。** 最近 24 月不能由截断月榜或年榜相加构造完整区间偏好。首版沿用结束日期所在自然年的偏好作为明确标注的年度补充；仅 `recent` 采用这一例外，按需保留一次该年度请求，结果不加入 24 月总量。偏好区域和各模块 `scope` 显示实际年度及截至日期，并注明“年度偏好，非最近 24 月汇总”，不能只藏在更多弹窗。查看其他年份使用已有全局自然年选择器，不新增第二套偏好年份状态，也不自动补抓所有年份；模拟、明细与导出使用同样口径。年度字段缺失如实说明，不回退到别年。年度与全历史榜单仍保留上游截断和展示阈值说明，作者时长仍是显示文字，按[作者排行](#authors)处理。
5. **逐项核对 27 个模块。** 每个模块的数据、标题、实际范围、说明、覆盖状态与导出相互一致；书架仍为“当前书架”，累计笔记与区间内正文分开说明。全历史未逐月或逐日采集的模块继续明确缺失原因，不伪造历史明细，也不为此默认无限扩展采集预算。旧全历史缓存若仅有当年偏好，不能换标签继续使用，应重聚合已有全历史结果；必要时明确提示重新读取。

范围恢复遵守[每个账号或游客会话仅一份临时报告](architecture.md#collection)的约束：当前会话有匹配且有效的报告时复用；前进/后退回到已被替换的范围时可按该范围重新生成，不能承诺同时缓存多个周期。同会话与跨登录会话的生成、确认及原页面失效行为统一见[报告生成与替换](architecture.md#report-replacement)；其他会话有有效报告时，刷新、恢复与前进/后退也不能绕过确认自动覆盖。这里“不重复采集”指同一次导航不因多个监听器启动重复任务，不禁止缺少有效缓存时的必要采集。快速切换必须同时防止旧创建请求、批次响应和笔记分页覆盖最后一次选择，仅丢弃前端显示不足以保证服务端当前任务正确。

月份联动、单书、分类、关键词和笔记类型等局部筛选仅影响页面展示；下载范围统一遵循[首版下载规则](architecture.md#export)，使用当前连接、当前统计范围的整份已采集报告。面板说明范围与局部筛选的区别，不把单书笔记跳转或月份联动当成导出范围变更。

依据：[微信读书官方阅读统计说明](https://github.com/Tencent/WeChatReading/blob/main/skills/readdata.md)。2026-10-04 已核对：`overall` 支持全部历史、`baseTime` 固定为 0；字段按模式与数据条件可选返回。实施时有界核验真实全历史回包，仅记录必要的脱敏字段和覆盖结论，不落盘凭据或真实正文。

### 图表与书架实施边界

- **单位及提示统一在现有组件处理。** 复用 `client/charts.ts` 和双端模块组件，清理树图、环图、雷达、词云的重复单位及失效留白。保留“相对权重不是百分比”等不可从图形直接读出的含义；无 hover 的移动端通过点按和明细表取得数值与单位。当前要求是删除重复的独立单位说明，保留数值轴、tooltip、明细及混合指标所需单位。
- **词云与离线导出一起选择实现。** 优先采用与现有 ECharts 兼容的词云扩展，仅在确有需要时增加相应依赖，不自建通用图表框架。接入前核验 ECharts 6、SVG 渲染、中文字体及离线 HTML 输出；导出等待字体与词云布局完成，避免空图、重叠和裁切，不退回标签堆排或只导出表格冒充完成。频次映射保持单调，限制最大最小字号，处理同频、单词、空结果与长词；不改变词频统计规则。
- **分类在共享数据入口统一。** 根据真实分类格式识别一级与二级，优先使用明确层级字段或已核实的分隔规则，不猜测分隔符；保留必要原始信息，双端、筛选和模块 17 使用同一归一化结果。有声内容和文章收藏沿用原有独立类别；“导入书籍”作为当前未分类条目的统一展示与筛选项。详情补充不能把已归一的一级分类恢复成二级，或用空值覆盖已有导入标识。
- **列表排版用现有 CSS 完成。** 为文本容器补足收缩约束，书名两行省略并保留两行高度，统一辅助文字与间距；不以 JavaScript 测量或硬截字符串实现。长书名、长作者名、缺失作者、导入书籍及封面失败时仍对齐，详情完整书名可读。

### 已核对问题与目标布局

当前 `server/collector.ts` 将作者与格式化时长拼成同一个 `label`，`client/charts.ts` 的条形长度只表示本数；坐标标签固定宽度并截断，导致作者、时长争抢空间，数值与视觉表达的主次不清。

每位作者作为一条记录：名称位于左侧，本数在右侧对齐；下一行显示较弱的时长文字与表示本数的横条。以下仅为排版示意，数值不代表真实阅读记录：

```text
余华                              6 本
阅读 32 小时       ━━━━━━━━━━━━━━━

史铁生                            3 本
阅读 18 小时       ━━━━━━━━
```

- 作者名称清晰显示，长名字允许换行；本数保留“本”单位，时长始终可见，不依赖悬停。

- 标题、必要说明和“查看更多”沿用[笔记、卡片与导航](#notes-and-navigation)的卡片层级；实际统计范围按[图表、时间范围与书架](#charts-range-shelf)展示，不能固定为自然年。保留榜单阈值与截断说明。

### 数据与实施范围

1. **拆分字段。** 在现有报告数据结构中分别保留作者名称、数值本数与可选的时长显示文字；从上游原始字段映射，不再把时长拼入作者标签后重新拆解。时长原样保留，不解析为数值，不参与排序或横条计算；缺失显示“—”，不补零。实际本数为零时保留零。
2. **双端与明细一致。** 复用现有模块容器、Dialog / Vant Popup，通过简单列表与 CSS 横条完成展示，不新增图表依赖或通用排行框架。明细列为“作者 / 阅读本数 / 阅读时长”，按卡片相同规则排序，显示全部已返回记录；其他模块继续使用各自的图表。
3. **模拟与导出同步。** `shared/demo.ts` 使用同样的字段结构，时长仅由示例自身已有记录生成并保持模拟标识。作者排行在离线 HTML 中直接输出静态列表与内嵌 CSS 横条，保留前 5 位预览及全部记录的三列明细，不进入通用 ECharts 转 SVG 分支；其他 ECharts 图表仍输出内嵌 SVG，与 [首版建议下载格式](architecture.md#export) 一致。JSON 保留拆分后的字段及全部返回记录，不能因卡片只展示前 5 位而丢失其余数据。旧缓存恢复路径一并核验，缺少独立时长字段时不得猜测数值。
4. **主要落点。** `shared/report.ts`、`server/collector.ts`、`shared/demo.ts`、双端 ReportModule 及样式、`client/export.ts`；实施后同步 [data-contract.md](../data-contract.md)、[design-system.md](../design-system.md) 与质量记录。本节只调整作者偏好，不扩展出版社或分类模块。

### 验收清单（均待实施后执行）

- [ ] 作者、本数、时长各有明确位置；长作者名可换行，数字与单位不被挤压，桌面/移动、明暗主题及 200% 缩放下均可读。
- [ ] 按本数降序、同值顺序稳定；横条比例与本数一致，零本数不产生错误宽度；不把格式化时长当数值或占比。
- [ ] 少于、等于和超过 5 位作者均正常；卡片截取规则明确，明细保留全部已返回记录；时长缺失、空数据、不可用及部分覆盖状态如实展示。
- [ ] 真实与模拟数据、旧缓存恢复、双端弹窗和 HTML/JSON 的作者、本数、时长与实际统计范围一致，范围遵循[图表、时间范围与书架](#charts-range-shelf)；导出不丢失前 5 位以外的数据。离线与打印使用静态作者列表及 CSS 横条，不重复生成旧柱状图；其他 ECharts 图表的 SVG 导出保持正常。
- [ ] 按改动风险运行已有测试、类型检查、lint 与双端构建，排版和交互通过浏览器人工核验；不新增或修改自动化测试，不编写临时断言脚本。失败与未验证项如实记录。
