# 官网与说明文档

日期：2026-11-21。实现、静态验证与 Chrome 交互验收：complete。

## 目标

让首次接触阅纹的读者在公开首页翻看模拟阅读数据，再按说明部署自己的实例并保存第一份报告。参考 Calends 的产品演示与按任务组织的指南，沿用阅纹的品牌和真实操作名称。

## 实现与验收

- 在 `site/` 建一个静态 Astro 项目，首页使用现有品牌资产及共享示例生成器；官网与 Starlight 用户文档共用根域，文档入口为 `/docs/`。
- 从现行自部署说明及应用代码整理入门、部署、授权和报告操作，只发布面向读者的内容。应用和官网独立构建。
- 构建并确认文档路由、中文搜索索引和静态产物；用 Chrome 检查首页示例、跳转与文档搜索。

## 进度

首页、五页文档和独立构建已完成。Chrome 已验证首页示例、键盘焦点、文档入口与中文搜索结果定位。验收中发现的月度柱高失真已修复并复查。[验证记录](../quality-log.md#website-2026-11-21)
