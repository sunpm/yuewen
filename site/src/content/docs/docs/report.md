在已配置授权的实例中，从「连接设置」点「查看报告」，或打开「阅读概览」。选择统计范围，点「开始采集」。

## 从一个问题开始

| 想了解什么                 | 从哪里看                                                     |
| -------------------------- | ------------------------------------------------------------ |
| 这段时间花了多少时间读书？ | 「阅读概览」看总时长和有效阅读天数，再看各月变化。           |
| 哪些书或作者占了最多时间？ | 「深度报告」看单书时长、分类和作者。先看图表标出的统计范围。 |
| 某本书读到哪里了？         | 在「我的书架」找到书名，打开详情看已采集的进度与笔记。       |
| 当时记下了什么？           | 在「阅读笔记」按书或关键词查找划线与想法。                   |

阅读时长按所选范围统计。书架反映采集时的状态，部分笔记指标是累计值；各图表会注明自己的范围。点选月份、书名或分类可以缩小当前视图。

## 只看到部分数据

先看「采集与期限」和模块的覆盖说明。上游暂未返回的数据会标明原因。阅读量较大时，PC 上可用「采集下一段」继续同一份报告；中断后按页面提供的「继续采集」或「重试未完成部分」操作。

刷新页面会恢复已有结果。需要继续读取时，请主动点采集按钮。当前报告两小时后过期，可在期限内[保存或下载](/docs/export/)。
