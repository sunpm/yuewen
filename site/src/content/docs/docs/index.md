---
title: 快速开始
description: 从示例了解阅纹，再生成自己的第一份微信读书报告。
---

阅纹把微信读书里的阅读时间、书架、划线和想法整理成一份个人报告。第一次使用，可以先[翻看官网的模拟报告](/#sample)，切换阅读时间、书架排行和划线，看看你能从中读到什么。

## 已经有阅纹实例

1. 打开实例地址，按 Cloudflare Access 的提示验证身份。
2. 进入「连接设置」，确认实例已配置微信读书读取授权。
3. 点「查看报告」，选择统计范围，再点「开始采集」。先从「阅读概览」看本期投入，再去「阅读笔记」回看具体内容。

当前报告保留两小时。想在下次重读，可在 PC 上保存历史快照，或[下载离线报告](/docs/export/)。

## 第一次自己部署

准备一个 Cloudflare 账户、能用于 Access 的域名，以及你自己的微信读书读取授权。先[部署实例](/docs/deploy/)，再[连接微信读书](/docs/connection/)。一个实例使用一个读取授权，所有获准访问者共享同一份报告及操作权限。

## 只在本机体验

从[阅纹源码仓库](https://github.com/sunpm/yuewen)下载代码，在仓库根目录使用 Node.js 22 和 pnpm 10 执行：

```sh
pnpm install
pnpm build
pnpm db:local
pnpm dev:api
```

打开 [PC 示例](http://127.0.0.1:8787/demo) 或 [H5 示例](http://127.0.0.1:8787/m/demo)。两者都使用模拟数据。这个开发入口仅供本机回环访问。
